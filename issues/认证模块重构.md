# 认证模块重构计划

## 修改密码接口重构

### 目标
将 `app/api/setting/change-password/route.ts` 接口按照 Controller -> Service -> DAL 的三层架构进行重构。

### 执行步骤

#### 第一步：扩充数据访问层 (DAL)
- 修改 `dal/userRepository.ts`
- 新增 `verifyPassword` 函数：验证用户密码
- 新增 `updatePassword` 函数：更新密码并更新时间戳

#### 第二步：强化业务逻辑层 (Service)
- 修改 `services/userService.ts`
- 新增 `changePassword` 方法
- 实现所有业务校验逻辑
- 调用 DAL 层的方法完成密码更新

#### 第三步：定义数据传输对象 (DTO)
- 修改 `models/user.ts`
- 定义 `ChangePasswordDto` 接口

#### 第四步：重构 API 控制层 (Controller)
- 修改 `app/api/setting/change-password/route.ts`
- 使用新的分层架构重写接口逻辑
